# Problem Statement

## Gujarat Hackathon 2026 — Challenge 7

### Smart Urban Flooding & Drainage Management System for Ahmedabad–Surat

**Domain:** Urban Infrastructure

### The Challenge

Rapid urbanization in cities like Ahmedabad and Surat has outpaced
stormwater drainage infrastructure, causing frequent monsoon flooding,
traffic disruption, and property damage due to poor predictive planning
and delayed civic response.

### Objective

Create Agentic AI solutions that:

- Predict flood-prone zones
- Optimize drainage maintenance schedules
- Coordinate real-time civic response during heavy rainfall events

### Suggested AI Agents

- Flood Risk Prediction Agent
- Drainage Maintenance Scheduling Agent
- Real-Time Civic Response Coordination Agent
- Citizen Flood Reporting Agent
- Urban Resilience Dashboard Agent
- Post-Disaster Damage Assessment Agent

### Required Technology

- IBM Bob
- IBM Granite LLM
- IBM Cloud

### FLOWSHIELD Alignment

FLOWSHIELD focuses primarily on the **real-time civic response
coordination** aspect of the challenge.

It provides a decision-support layer that helps authorities:

1. Understand incoming flood information
2. Validate and structure emergency reports
3. Identify people at risk
4. Prioritize life-safety incidents
5. Allocate limited response resources
6. Coordinate recommended actions
7. Replan when the situation or resource availability changes

This implementation is designed as an evolution toward a broader urban
flooding and drainage management platform.
